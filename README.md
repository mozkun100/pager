# المنبه (Pager)

بديل جهاز البيجر في المطاعم والكافيهات: العميل يصوّر QR، يكتب رقم طلبه، وجواله ينبهه لما يجهز الطلب. بدون تطبيق وبدون تسجيل.

## التشغيل

1. ثبّت **Node.js** (نسخة 22 أو أحدث) من https://nodejs.org (اختر LTS).
2. نزّل المشروع وادخل مجلده، وثبّت المكتبات (مرة وحدة):
   ```
   npm install
   ```
3. شغّل السيرفر:
   ```
   npm start
   ```

## الصفحات

| الصفحة | الرابط |
|---|---|
| لوحة الكاشير | `http://localhost:3000/cashier` |
| صفحة العميل | `http://<عنوان-الكمبيوتر>:3000/` (يطبعه السيرفر عند التشغيل) |
| طباعة الـ QR | `http://localhost:3000/qr` |

## رمز الدخول (PIN) للوحة الكاشير
- أول مرة تفتح لوحة الكاشير تختار رمز من 4 أرقام.
- كل جهاز جديد يدخل الرمز مرة وحدة، وبعدها يتذكره. زر "🔒 قفل" يطلّع الجهاز.
- تغيير الرمز من ⚙️ الإعدادات، وبعدها كل الأجهزة الثانية تطلع وتدخل الرمز الجديد.
- 5 محاولات غلط ← الجهاز يتقفل دقيقة.
- **نسيت الرمز؟** وقّف السيرفر واكتب: `npm run reset-pin` (الطلبات ما تنمسح).

## الملفات

| الملف | وظيفته |
|---|---|
| `server.js` | السيرفر: الصفحات، الاتصال المباشر، وأوامر الطلبات |
| `db.js` | قاعدة البيانات (SQLite المدمجة في Node) والترقيم |
| `public/cashier.*` | لوحة الكاشير |
| `public/customer.*` | صفحة العميل |
| `public/alarm.js` | التنبيه: الصوت، الاهتزاز، منع انطفاء الشاشة |
| `public/i18n.js` | كل النصوص بالعربي والإنجليزي |
| `public/qr.html` | صفحة طباعة الـ QR |

البيانات تنحفظ في `data/pager.db`.

## الاستضافة لاحقاً
عيّن متغير البيئة `PUBLIC_URL` برابط الموقع الحقيقي (مثل `https://pager.example.com`) عشان يطلع في الـ QR.

## قيود المتصفحات
- الصوت يحتاج ضغطة من العميل ("فعّل التنبيه")، ومرة ثانية بعد تحديث الصفحة.
- الاهتزاز في أندرويد فقط.
- منع انطفاء الشاشة يحتاج `https` (ما يشتغل في التجربة المحلية).
- لازم الصفحة تبقى مفتوحة وظاهرة. لو انقفلت الشاشة ممكن المتصفح يوقف الصوت.
