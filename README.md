# المنبه (Pager)

بديل جهاز البيجر في المطاعم والكافيهات: العميل يصوّر QR، يكتب رقم طلبه، وجواله ينبهه لما يجهز الطلب.

## التشغيل

1. ثبّت **Node.js** (نسخة 22 أو أحدث) من https://nodejs.org (اختر LTS).
2. نزّل المشروع وادخل مجلده:
   ```
   git clone https://github.com/mozkun100/pager.git
   cd pager
   ```
3. ثبّت المكتبات (مرة وحدة بس):
   ```
   npm install
   ```
4. شغّل السيرفر:
   ```
   npm start
   ```
5. السيرفر يطبع الروابط:
   - لوحة الكاشير: `http://localhost:3000/cashier`
   - صفحة العميل من الجوال: `http://<عنوان-الكمبيوتر>:3000/` (لازم الجوال على نفس الواي فاي)

## التقنيات
- Node.js + Express: السيرفر
- Socket.IO: الاتصال المباشر
